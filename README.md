## 📌 Sobre o projeto

O **SISVET (Sistema Integrado de Saúde Veterinária)** é uma plataforma web idealizada para centralizar e facilitar o gerenciamento de informações relacionadas à saúde animal.

A proposta é conectar tutores, médicos-veterinários e clínicas em um ambiente digital, permitindo o acesso organizado ao histórico de saúde dos animais, incluindo consultas, vacinação, medicamentos e documentos veterinários.

O projeto busca contribuir para uma gestão mais eficiente das informações, promovendo a organização dos registros e facilitando o acompanhamento da saúde dos animais.

## 🎯 Objetivos

- Centralizar informações e registros de saúde animal.
- Facilitar o acompanhamento do histórico veterinário.
- Permitir o gerenciamento de animais vinculados aos seus tutores.
- Organizar registros de consultas, vacinas, medicamentos e documentos.
- Implementar mecanismos de autorização e controle de acesso.
- Desenvolver uma estrutura preparada para integração com APIs e banco de dados.

## 🏗️ Estrutura do sistema

O SISVET está sendo desenvolvido para atender diferentes perfis de usuários:

- **Tutores:** gerenciamento dos animais e consulta às informações autorizadas.
- **Médicos-veterinários:** registro e acompanhamento das informações clínicas dos animais, conforme as permissões concedidas.
- **Clínicas veterinárias:** organização das informações e apoio ao gerenciamento dos atendimentos.

A arquitetura e as permissões serão refinadas durante o desenvolvimento.
